# Karlo Diaz Portfolio V2

## Files
- `index.html` — About, Works and Contact
- `project.html` — reusable project page
- `projects.js` — project titles, roles, gear, software, images and YouTube links
- `script.js` — homepage, intro and transitions
- `project.js` — project-page rendering and Previous/Next transitions
- `styles.css` — full responsive design

## Add a new project
1. Add a new folder under `projects/` with three images.
2. Add one object to the top of the `PROJECTS` array in `projects.js`.
3. Keep the array in newest-to-oldest order. Previous/Next navigation updates automatically.

## Intro behavior
The intro plays once per browser tab/session. Desktop uses `LOGOINTROMP4.mp4`; phones use `LOGOINTROPHONE.mp4`.
